# El Campo

**El Campo** is an **Object-Oriented Programming (OOP) project** designed to connect rural producers and farmers with consumers, providing a platform where agricultural products can be **sold, exchanged, and shared** directly between communities.

## Project Overview

The application provides a graphical interface through which users can interact with the platform and manage their products and exchanges.

## Main Concept

The platform is built around two main types of users:

* **Rural producers / farmers** — can offer agricultural products and make them available to other users.
* **Consumers** — families and individuals who can browse available products, purchase them, or exchange products with other users.

By connecting these two groups directly, **El Campo** explores how software can facilitate the distribution and exchange of agricultural products while providing a practical application of object-oriented design principles.
